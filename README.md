# Парастоси

Апликација за телефон (PWA) за евиденцију упокојених и подсетник за парастосе:
40 дана, пола године и година. Замењује Excel табелу.

- **Апликација:** https://jombebrat.github.io/sahrana/
- **Подаци:** Supabase (Postgres). У овом репозиторијуму нема података, само код.

## Шта ради

- Екран **Предстоји**: помени ове недеље, у наредних 14 и до 60 дана.
- **Обавештење** на телефон 14 дана пре сваког помена и кад породица пошаље податке.
- **Линк за породицу**: формулар на српском (ћирилица) или француском; запис стиже у апликацију сам.
- Правила за датуме су у `supabase/functions/parastosi/pomeni.ts`, са тестовима у `src/pomeni.test.ts`.

## Правила за датуме (из Excel-а)

| Помен | Правило |
| --- | --- |
| 40 дана | датум смрти + 40 дана |
| Пола године | исти дан, 6 месеци касније (ако дан не постоји, последњи дан месеца) |
| Година | исти дан и месец следеће године |

## Развој

```bash
npm install
npm run dev          # http://localhost:5173/?demo приказује измишљене податке
npm test             # тестови правила за датуме
npm run build        # прави dist/
```

Објава: садржај `dist/` иде на грану `gh-pages` (GitHub Pages).

## Делови

- `src/` – апликација (React, TypeScript, Vite)
- `public/sw.js` – обавештења и рад без интернета
- `supabase/migrations/` – шема базе и правила приступа (RLS)
- `supabase/functions/parastosi/` – серверска функција: пријава преко линка, дневна обавештења, прво подешавање
